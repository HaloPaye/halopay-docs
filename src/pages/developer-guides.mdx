# Developer Guides

Set up the HaloPay environment locally to build and test features. 

## Prerequisites
- Node.js (v18+)
- Stellar testnet account
- PostgreSQL (if running a local database)

## Setup halopay-api
Clone the repository and run the API.
```bash
cd halopay-api
npm install
npm run dev
```

### Environment Variables
Configure these variables in your `.env` file.
| Variable | Description |
|---|---|
| `PORT` | API Port (default: 3000) |
| `STELLAR_NETWORK` | `TESTNET` or `PUBLIC` |
| `ANCHOR_HOME_DOMAIN` | Stellar Anchor domain for SEP-10 |
| `SIGNING_SEED` | Merchant custodian seed |

## Setup halopay-pos
Clone the repository and run the frontend POS.
```bash
cd halopay-pos
npm install
npm run dev
```
The POS terminal starts on port `3001` by default.
