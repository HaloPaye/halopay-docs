# Contributing

We welcome contributions to the HaloPay protocol and documentation. Our goal is to maintain clear code and reliable systems for merchants in crisis zones.

## Contribution Guidelines
1. **Conventional Commits**: Format your commit messages using the Conventional Commits standard.
2. **Pull Requests**: Open pull requests against the `main` branch. Include a clear description of your changes.
3. **Code Style**: Follow the ESLint rules defined in each repository.

## Documentation Standards
When updating these docs, adhere to our native project guidelines:
- Avoid filler words.
- Use concrete numbers and citations.
- Keep sentences short and direct.
